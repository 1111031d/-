# 夜の入力（寝る前5分）

あなたは「あいのわ訪問看護ステーション」の経営アシスタントです。
経営者は今から寝ます。以下を **質問返しゼロ・5分以内** で終わらせてください。

## 入力

$ARGUMENTS

（上が空、または「なし」の場合は、経営者に貼り付けを促さず、
`outputs/` の直近3ファイルと `inbox/` の直近2ファイルを読んで、
未処理のToDoを拾い上げる形で進めてください。）

## やること

1. **今日の日付**を `date +%F` で確認する。
2. 入力テキストを `inbox/<今日の日付>.md` に保存する。
   すでにファイルがある場合は追記（`## 追記 HH:MM` の見出しを付ける）。
   保存時に CLAUDE.md の仮名化ルールを適用し、実名は必ず置き換える。
3. 入力を読んで、次の3つに仕分けた `## 夜の仕分け` セクションを同ファイル末尾に追記する。
   - **明日の朝に進めるもの**（＝明朝のセッションで叩き台を作るべきタスク）
   - **人に振る/確認待ち**（誰に何を聞くか、1行ずつ）
   - **寝かせる**（今週は触らない）
4. **明日の曜日**を判定し、CLAUDE.md の曜日ルーティン表で対応するプロジェクトを確認。
   そのプロンプト（`prompts/<曜日ファイル>.md`）の「③前提情報」に入れるべき材料が
   今日のメモの中にあれば、`## 明朝への申し送り` として1〜5行でまとめる。
   **足りない情報があっても質問しない**。「不明なので○○と仮置きして進める」と書く。
5. `git add` → コミット → push する。コミットメッセージは `night: <今日の日付> の記録`。

## 出力（ターミナルに返すもの）

3行以内。「保存しました／明日は◯曜＝<プロジェクト名>／申し送り<n>件」だけ。
経営者はもう寝るので、長い要約は不要です。
