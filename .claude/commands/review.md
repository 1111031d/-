# 朝の成果物レビュー（出勤後 or 昼休み）

`outputs/` の今日（または `$ARGUMENTS` で指定された日付）のファイルを読み、
経営者からのフィードバックを反映します。

## 手順

1. 対象ファイルを列挙し、それぞれの「✅ 確認ポイント」と「判断待ち」を提示する。
2. 経営者のコメント（`$ARGUMENTS` の残り、または対話で受け取る）を反映して修正する。
   - **採用** → ファイル冒頭に `status: adopted` を追記。以後変更しない。
   - **差し戻し** → 何がズレていたかを1行で記録し、修正版を書く。
3. 差し戻しの理由は `docs/feedback-log.md` に1行追記する（曜日・プロジェクト・理由）。
   これが土曜の週次振り返りで型をチューニングする材料になります。
4. コミットして push。
