# 完了の記録

**`/review 今日は◯◯をやった` と打つだけです。** 予定ではなく、**終わったこと**を書きます。

## 入力

$ARGUMENTS

## やること

1. `TZ=Asia/Tokyo date +"%F %a"` で今日の日付と曜日を確認する。
2. **`docs/sprint-log.md` の表に1行追記する。**
   列は「日付／曜／テーマ／完了したこと／規模（大・中・小）」。
   規模は所要時間から判断する（〜7分=小、〜20分=中、それ以上=大）。
   **大・中・小のどれでも1件は1件**として数える。
3. 入力の中に**数字**（売上、固定費、訪問件数、損益分岐、あと何件）が含まれていたら、
   `docs/sprint-log.md` の「押さえておく数字」の表を更新し、更新日を入れる。
4. その日の `outputs/<日付>-sprint.md` があれば、該当する1手に `✅ 完了` を追記する。
5. 成果物への差し戻し（「この文章はズレている」等）が含まれる場合は、
   対象ファイルを修正し、何がズレていたかを1行で記録する。
6. commit して push する。

## 出力（ターミナルに返すもの）

2行以内。「記録しました（今週◯件目）」と、数字が更新された場合はその数字だけ。
励ましや要約は不要です。
