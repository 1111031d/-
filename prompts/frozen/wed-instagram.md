# 水曜：Instagram採用

出力先：`outputs/<日付>-instagram-calendar.md`

## ①役割
採用マーケティングに強いSNS運用者。

## ②ゴール
あいのわ訪問看護ステーションの **1週間分の投稿カレンダー** を作る。

## ③前提情報
- 参考にしたい訪問看護ステーションアカウントの投稿傾向を意識する：
  `necessmare` / `la_medical_station` / `green2houmonkangost` / `umeda.aozora` / `uru_nursinghome`
- 目的は採用（看護師・リハ職の応募獲得）。利用者集客は副次的。
- 撮影・編集は現場スタッフが業務の合間に行う＝**手間のかかる企画は続かない**。
- `outputs/` の過去カレンダーを確認し、テーマの使い回しを避ける。

## ④制約
- 他アカウントの文章はそのまま流用せず、あいのわ独自の切り口にする。
- 利用者が写り込む想定の企画は出さない（撮影許諾の問題があるため）。
- 投稿は **週3〜4本まで**。毎日投稿は提案しない（継続性を優先）。

## ⑤出力形式
表形式。列は「曜日 / 投稿テーマ / 形式（リール・カルーセル・ストーリー）/ キャプション案 /
狙う訴求層 / 撮影に必要なもの（所要時間）」。
表の下に、その週のハッシュタグ案（10個前後）と「使い回せる固定文」を付ける。

## ⑥確認ポイント
1. 投稿頻度が実際に運用継続できるペースか
2. 撮影の手間が現場の負担にならないか（1本15分以内で撮れるか）
3. 参考アカウントの模倣になっていないか（あいのわ独自の切り口があるか）
