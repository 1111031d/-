# inbox — 入力の置き場

**ここに投げるだけで、翌朝プロジェクトが1歩進みます。**

- ファイル名は `YYYY-MM-DD.md`（`/night` を使えば自動で作られます）
- 形式は自由。走り書き・音声入力の書き起こし・議事録の丸貼りでOK
- 整理しなくて構いません。整理は Claude 側の仕事です

## 書くとよいこと（思い出せる範囲でOK）
- 今日あったこと／決めたこと／決められなかったこと
- 誰かに言われたこと（スタッフ、ケアマネ、家族、業者）
- 明日の朝に進めてほしいこと（一言でOK）
- 曜日プロジェクト用の材料
  （木曜なら「スカウトしたい人：訪問看護5年、上尾市在住」のような1行）

## 注意
実名で書いても構いません。`/night` の保存時に仮名化されます。
