# 既存スプレッドシートの分析と、今後の方針

分析日: 2026-09-08
対象: 「訪問看護計画書・報告書・サービス提供表 管理表（提出先別レイアウト版）」

## 1. 既存スプレッドシートの構造

| シート | 内容 |
|---|---|
| 管理表 | 利用者 × 対象月で1行。書類ごと・提出先ごとに提出日と状況（全23列） |
| 使い方 | 運用ルールの説明 |
| 利用者マスタ | No / 利用者名 / 主治医 / 医療機関 / 訪問頻度 / 保険種別 / ステータス |

### 管理表の列構成

| 書類 | 提出先 | 記録する内容 |
|---|---|---|
| 計画書 | 主治医 / ケアマネ / 本人 | 作成日、提出期限、提出先ごとの提出日と状況 |
| 報告書 | 主治医 / ケアマネ | 作成日、提出期限、提出先ごとの提出日と状況 |
| サービス提供票 | ケアマネのみ | 提出期限、提出日、状況 |

状況は数式で自動判定（済み / 期限間近7日以内 / 期限超過 / 期限未設定 / 対象外）。

## 2. 実データで見つかった問題

いずれも「スプレッドシートに直接入力する」やり方の限界から来ている。
使う人の問題ではなく、仕組みの問題。

| 箇所 | 問題 |
|---|---|
| 湊洋之さんの行 | サービス提供票の状況が `#VALUE!` エラー。期限欄に「8月は不要」という文字を入れたため数式が計算できていない |
| 小川俊一・稲橋忠一さんなど | 計画書の作成日欄に「9月は不要」という文字。ルール上は期限欄に「対象外」と入れるはずだった |
| 本人への提出 | 13名中9名が「期限超過」。ルールと実態が合っていない |
| 利用者マスタ | 主治医・医療機関・訪問頻度・保険種別が全員空欄。マスタが機能していない |
| 韮澤清さん | マスタにいるが、管理表に行がない |

### 原因

1. **日付欄に文字を書けてしまう** → 数式がエラーになる
2. **「対象外」をどこに書くかを覚えていないと守れない**
3. **23列を横スクロールするため、埋め忘れに気づきにくい**
4. **誰がいつ更新したか残らない**

## 3. 方針（決定）

**データは今のスプレッドシートのまま。その上にアプリの画面をかぶせる。**

スプレッドシートを捨てない。列を少し整理したうえで、
Google Apps Script の Web 画面から読み書きする。

| | スプレッドシート直接 | アプリ画面ごし |
|---|---|---|
| 23列の横スクロール | 必要 | 不要（未提出だけ表示） |
| 日付欄への文字入力 | 書けてしまう → エラー | 書けない（ボタンとカレンダー） |
| 「不要」の扱い | 手で「対象外」と入力 | 自動判定（下記） |
| 更新者の記録 | 残らない | 自動で残る |
| 元のスプレッドシート | — | そのまま残る。いつでも開ける |

## 4. 運用ルール（第3回ヒアリングで確定）

### 計画書の作成サイクル

- 基本は**指示書の更新に合わせて**作成する
- 6ヶ月の指示書の方は、毎月見直しをしたうえで、**3・6・9・12月に作り直す**

→ アプリでは利用者ごとに次の3つから選ぶ形にする。
　その月に不要な人は**自動で「対象外」表示**になるため、「9月は不要」と手で書く必要がなくなる。

| 設定 | 意味 |
|---|---|
| 3・6・9・12月 | 四半期ごとに作り直す（6ヶ月指示書の方） |
| 毎月 | 毎月作成する |
| 指示書の更新月 | 指示書の有効期限が来る月に作成する |

### 本人への提出

「計画書のサインをもらう形」で運用している。
→ 列名を「本人サイン」に変更。利用者ごとに「もらう / 不要」を設定できるようにする。
　（不要な人には警告が出ないので、期限超過だらけの状態が解消される）

### 個別の例外（第4回ヒアリングで確定）

「9月は不要」と書かれていた2名は、3・6・9・12月のルールから外れたのではなく、
**終了予定などの個別の事情**だった。つまりサイクルのルール自体は正しい。

→ アプリでは、その月だけ計画書を不要にする「今月は不要」ボタンを用意する。
　押すと理由（終了予定 / 入院中 / サービス中止中 / その他）を選ぶ形にする。
　日付欄に文字を書かずに済むので、`#VALUE!` エラーが起きない。
　理由がそのまま記録として残るので、後から見返したときに分かる。

### 対象月

8月分の書類の提出期限は9月4日。9月に作業するときは「8月分」を見る。
→ アプリは**前月分を初期表示**する。

### 自動で対象外になるもの

- ケアマネが付いていない方（医療保険のみなど）→ ケアマネ欄
- 医療保険の方 → サービス提供票
- 計画書の作成月でない方 → 計画書の3欄すべて
