# 利用者一括管理アプリ 要件メモ

作成日: 2026-09-08 / ヒアリングに基づく暫定版

## 1. 前提・方針

- **データの置き場所**: Googleスプレッドシート
- **画面の作り方**: Google Apps Script の Web アプリ（スプレッドシートに付ける仕組み。追加費用なし）
- **主な利用端末**: パソコン
- **使う人**: スタッフ全員（看護師・リハビリ職を含む）

### 最重要の方針: カイポケと二重入力しない

利用者の基本情報（住所・保険情報など）はカイポケが正。
このアプリは「カイポケに無い / カイポケでは一覧で見えない情報」だけを持つ。

つまり作るのは **利用者名簿ではなく「抜け漏れ管理ボード」**。

| 情報 | 持つ場所 |
|---|---|
| 住所・保険情報の詳細・請求 | カイポケ（アプリには持たない） |
| 氏名・かな・保険区分・利用状況 | アプリにも最低限コピー（検索と表示のため） |
| 担当スタッフ | アプリ |
| 医療機関・主治医・居宅事業所・ケアマネ | アプリ |
| 書類の提出済み / 未提出 | アプリ |

## 2. 解決したい困りごと（優先順）

1. **書類の提出・更新漏れ** … 計画書・報告書・実績・契約書類
2. **探すのに時間がかかる**
   - この医療機関 / ケアマネの担当利用者は誰か
   - 書類が未提出なのは誰か

## 3. 管理する書類

### 毎月発生するもの（月次書類）

| 書類 | 提出先 | 対象 |
|---|---|---|
| 訪問看護計画書 | 主治医 | 全員 |
| 訪問看護報告書 | 主治医 | 全員 |
| 実績 | ケアマネ | 介護保険の利用者のみ |

### 初回のみのもの（契約書類）

- 契約書
- 重要事項説明書
- 個人情報同意書

→ 揃っているかのチェックのみ。利用者マスタに持つ。

### 期限を管理するもの

| 書類 | 管理内容 |
|---|---|
| 訪問看護指示書 | 有効期限。残り30日で黄色、期限切れで赤く表示する |

### 今回は対象外

- **モニタリング月**: リハビリ対象者がまだいないため、今回は作らない。
  ただし後から追加できるよう、列だけ用意しておく。

## 5. 画面（案）

### 画面1: 今月の提出状況ボード（メイン画面）

- 上部に件数サマリ … 利用中 / 計画書未 / 報告書未 / 実績未 / 指示書 要対応
- 利用者ごとに行を並べ、計画書・報告書・実績のチェックボックスを置く
- チェックすると即スプレッドシートに保存（誰がいつ押したか記録）
- 「未提出だけ表示」ボタンで一発絞り込み
- 月は切り替えられる（先月分の遡り修正ができる）
- 指示書の期限が近い人・切れている人が同じ行で分かる

### 画面2: 利用者一覧・検索

- キーワード検索（氏名・かな・医療機関・ケアマネ）
- 絞り込み … 保険区分 / 利用状況 / 担当NS / 医療機関 / 居宅事業所
- 行をクリックすると詳細と編集
- 契約書類の「揃っていない人」だけ表示するボタン

### 画面3: 利用者の登録・編集

- 新規登録と修正。項目はシートAの通り
