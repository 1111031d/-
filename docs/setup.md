# 運用マニュアル：1日2回、入力するだけで回す

## 全体像

```
 夜（寝る前3分）              朝（5:00-6:00 運動中）        出勤後（30秒）
┌──────────────┐        ┌──────────────┐        ┌──────────────┐
│ /night <メモ> │  ───▶  │   /morning    │  ───▶  │   /review     │
│               │        │               │        │               │
│ inbox/ に保存 │        │ 曜日を判定    │        │ 確認ポイント  │
│ 明朝への申し  │        │ 前夜の材料を  │        │ だけ見て      │
│ 送りを作成    │        │ 読む          │        │ 採用/差し戻し │
└──────────────┘        │ 叩き台を生成  │        └──────┬───────┘
                         │ outputs/ に   │               │
                         │ commit & push │               ▼
                         └──────────────┘        docs/feedback-log.md
                                                        │
                                                        ▼
                                              土曜 /morning で型を自動改善
```

**入力は2回だけ。** 曜日の判定、前提情報の読み込み、出力先、コミットはすべて自動です。

---

## 1. 夜（寝る前3分）

スマホから claude.ai/code でこのリポジトリのセッションを開き、こう打つだけ：

```
/night 今日あったこと。ケアマネD事業所から新規相談、来週火曜カンファ。
看護師Cが連絡ツールの分散に困ってる。スカウト枠が3つ余ってる。
対象は訪問看護3年・上尾市在住・日勤希望。
```

- 整形は不要。走り書き・音声入力そのままでOK
- 実名で書いて構いません（保存時に仮名化されます）
- **何もない日は `/night` だけ**打てば、未完了ToDoを拾って翌朝に繰り越します

## 2. 朝（5:00〜6:00 / 運動・プランニング中）

```
/morning
```

これだけ。曜日を見て、その日のプロジェクトの叩き台を作り、`outputs/` に保存して
push まで終わらせます。**途中で質問は返しません**（手が空いていない前提で設計）。

特別な指示がある日だけ引数を足します：

```
/morning 今週は求人の応募が0件なので、スカウトより求人票の見直しを優先して
```

## 3. 出勤後（30秒）

`outputs/` の今日のファイルを開き、冒頭の **「✅ 確認ポイント」3つ** だけ見ます。

- OK → そのまま使う
- NG → `/review 火曜のSEO記事、上尾市の描写が一般論すぎる` と打つ

差し戻し理由は `docs/feedback-log.md` に自動で溜まり、**土曜の `/morning` が
その週のログを読んでプロンプト自体を直します**（最大3箇所まで）。
これで型が毎週ひとりでに実態へ寄っていきます。

---

## 4. 自動化（任意）：朝5時に自動で走らせる

`/morning` すら打ちたくない場合、スケジュール実行を登録できます。
毎朝5:00（JST）に自動でセッションが立ち上がり、叩き台ができた状態で起きられます。

- 登録内容：cron `0 20 * * *`（UTC）＝ 毎日 5:00 JST、プロンプトは `/morning`
- 完了通知をスマホに飛ばす設定も可能
- 登録・停止は Claude に「朝5時の自動実行を止めて」と言えばOK

> **夜は自動化しません。** メモの入力は人にしかできないためです。
> 逆に言うと、この仕組みで人が手を動かすのは「寝る前の3分」だけになります。

---

## 5. 精度を上げるコツ

1. **`areas/aiwanowa-profile.md` の `[要記入]` を埋める。**
   ここが埋まるほど、朝の出力が「あいのわ用」になります。埋めるのは1回だけ。
2. **`areas/scout-prompt-jobmedley.md` に既存の保存済みプロンプトを貼る。**
   現状は雛形が入っています。
3. **プロジェクトを増やすときは `prompts/00-template.md` をコピー**して
   `CLAUDE.md` の曜日表に1行足すだけ。コマンド側の変更は不要です。
4. **`inbox` に書く量を増やす**のが、出力品質への一番効くレバーです。
   差し戻し理由が「情報不足」ばかりなら、直すべきはプロンプトではなく夜の入力量です。
