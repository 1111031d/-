# 使い方マニュアル（IT用語なし版）

## この仕組みは何か

**あなたが夜に3分メモを書くと、朝起きたときに仕事の下書きができている**、という仕組みです。

Claude は毎回まっさらな状態で会話が始まるので、本来なら毎朝
「あなたは訪問看護の経営アシスタントで、上尾市にあって、訪問介護はやっていなくて…」
と説明し直す必要があります。それが面倒なので、**説明文をこの棚に置いておいて、
Claude が毎回勝手に読むようにした** ——それだけの仕組みです。

## 覚えるのは3つの合図だけ

Claude との会話画面で、下の3つを打つだけです。
（`/` から始まる文字は「決まった作業をまとめて呼び出す合図」です。
 電話の短縮ダイヤルのようなもので、中身は `prompts` フォルダに書いてあります）

### ① 夜、寝る前（3分）

```
/night 今日あったことを思いつくまま書く
```

例：

```
/night ケアマネのD事業所から新規相談。来週火曜にカンファ。
看護師Cが連絡ツールの分散に困ってると言っていた。
スカウト枠が3つ余ってる。訪問看護3年・上尾市在住・日勤希望の人に送りたい。
```

- きれいに整える必要はありません。走り書き・音声入力そのままでOK
- 利用者さんやスタッフの実名で書いて構いません（保存するときに仮名に置き換えます）
- 何もない日は `/night` だけ打てば、やり残しを翌朝に繰り越します

### ② 朝、起きた直後（打つのは1行だけ）

```
/morning
```

これだけで、今日が何曜日かを見て、その曜日の仕事の下書きを作ります。
運動している間に仕上がり、`outputs` フォルダに入っています。

特別な事情がある日だけ、後ろに一言足します：

```
/morning 今週は応募が0件なので、スカウトより求人票の見直しを優先して
```

### ③ 出勤後（30秒）

`outputs` フォルダの今日のファイルを開き、**いちばん上の「確認ポイント」3つだけ**見ます。

- 問題なければ、そのまま使う
- 直したいところがあれば `/review 火曜の記事、上尾市の話が一般論すぎる` と打つ

直した理由は自動で記録され、**土曜の `/morning` がその記録を読んで、
プロンプト自体を直します**。使うほど、あなた用に寄っていきます。

---

## フォルダの中身（どこに何があるか）

| フォルダ | 何が入っているか |
|---|---|
| `inbox` | **あなたが入れるもの。** 夜のメモ |
| `outputs` | **出てくるもの。** 朝できた下書き |
| `prompts` | 曜日ごとの「Claudeへの指示書」。中身を直せば出力が変わります |
| `areas` | 事業所の基本情報など、ずっと変わらない前提 |
| `CLAUDE.md` | Claude が毎回自動で読む共通ルール（仮名化する、誇張しない等） |
| `docs` | このマニュアルと、差し戻しの記録 |

---

## 最初にやること（1回だけ）

1. **`areas/aiwanowa-profile.md` の `[要記入]` を埋める。**
   スタッフの人数、開設年、算定している加算など。
   ここが埋まるほど、朝の下書きが「よそ行きの一般論」から「あいのわの話」になります。
   埋め方が分からない項目は `[要記入]` のまま残してください。
   空欄のままなら、Claude は勝手に想像せず「不明」として扱います。

2. **`areas/scout-prompt-jobmedley.md` に、いま使っているスカウト文のルールを貼る。**
   今は仮の内容が入っています。

3. **今夜 `/night` から始める。** 完璧に埋まっていなくても動きます。

---

## 自動化の状態（設定済み）

**朝の `/morning` は、毎朝5:30に自動で動くように登録済みです。**

- 5:30に自動でセッションが立ち上がり、散歩とHIITをしている間に叩き台ができます
- **6:20のプランニングの時点で、読める状態になっています**
- 終わるとスマホに通知が届きます
- 特別な指示がある日だけ、手で `/morning 今日は〜を優先して` と打ち直してください
- 止めたいときは「朝5時半の自動実行を止めて」と言えば解除します

**夜の `/night` は自動化していません。** あなたの頭の中にしかない情報なので、
人が入れるしかありません。**この仕組みで人が手を動かすのは、夕食後の3分だけ**になります。

---

## うまくいかないときの見分け方

| 症状 | 原因 | 対処 |
|---|---|---|
| 下書きが一般論すぎる | 夜のメモの情報が少ない | `/night` に書く量を増やす |
| 毎回同じところを直している | 指示書が実態と合っていない | `/review` で理由を記録 → 土曜に自動修正される |
| 前提が間違っている | プロフィールが空欄 | `areas/aiwanowa-profile.md` を埋める |
| 曜日のテーマを変えたい | — | `CLAUDE.md` の曜日の表を1行書き換える |
