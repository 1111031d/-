実際に運用できる形にまとめた資料一式です。

## 訪問看護に必須の法定研修（要点）

運営基準上の**義務**（未実施は運営基準違反）：

| テーマ | 頻度 |
|---|---|
| 感染症の予防及びまん延の防止のための研修 | 年1回以上 ＋ 新規採用時 |
| 感染症の発生を想定した訓練（シミュレーション） | 年1回以上 |
| 感染症対策委員会の開催 | おおむね6か月に1回以上 |
| 業務継続計画（BCP）に関する研修 | 年1回以上 |
| 業務継続計画（BCP）に関する訓練 | 年1回以上 |
| 高齢者虐待の防止のための研修 | 年1回以上 ＋ 新規採用時 |
| 虐待防止委員会の開催・担当者の設置 | 定期的（年1回以上） |
| 身体的拘束等の禁止と、行った場合の記録 | 常時（拘束時は都度記録） |

他法令上の義務・強く推奨されるもの：ハラスメント対策（措置義務）、雇入れ時の安全衛生教育、
個人情報保護の教育、医療安全・事故発生時の対応、ストレスチェック（50人以上で義務）。

個別要件：精神科訪問看護基本療養費を算定する看護師等は、
①精神科病棟・外来1年以上 ②精神疾患を有する者への訪問看護1年以上
③精神保健業務1年以上 ④20時間以上の研修修了 のいずれかを満たすこと。

## 運用の大原則

研修は「実施した」だけでは足りません。次の4点がそろって、はじめて実施と認められます。

1. 年間研修計画（01のシート②）
2. 研修実施記録（02の様式1）
3. 出席簿（02の様式2）
4. 当日使用した資料（03のレジュメ等）

欠席者は必ず後日フォローし、その記録（02の様式5）も残してください。全員受講が原則です。
