## いま未整備で、先に手を打つべき項目

1. **ハラスメント外部窓口の連絡先掲示** — 外部窓口は顧問社会保険労務士と決まっている。連絡先を事務所内に掲示し職員へ周知する。
2. **応援協定の書面化** — 訪問看護ステーションみやびとの相互応援。3名体制では2名欠けると事業が止まるため、BCP上いちばん効く対策。未締結でも「協議した記録」を委員会議事録に残す。
3. **上尾市の事故報告の基準・様式** — 未確認。介護保険課に確認して業務マニュアル第3章に追記する。
4. **緊急連絡先の電話番号** — 一部空欄。実際の番号を記入し、年2回かけて確認する。
5. **精神科訪問看護** — 現在対象利用者0名。算定しない期間は年間計画から外してよい。今後受け入れる場合は、訪問する職員全員が算定要件（経験1年以上または20時間以上の研修修了）を満たすか確認が必要。
6. **記録の保存年数** — 国の基準は完結の日から2年間。埼玉県の条例で5年の場合があるため確認する（各資料は安全側に倒し5年と記載）。

## 運用の大原則

研修は「実施した」だけでは足りません。次の4点がそろって、はじめて実施と認められます。

1. 年間研修計画（01 シート②）
2. 研修実施記録（02 様式1）
3. 出席簿（02 様式2）
4. 当日使用した資料（03 レジュメ）

委員会は「開催しただけ」では足りず、議事録＋周知の記録まで必要です。
訓練は「実施しただけ」では足りず、出た課題をBCP・マニュアルに反映した記録まで必要です。
