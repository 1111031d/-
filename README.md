# あいのわ訪問看護ステーション 経営OS

夜に3分メモを入れ、朝に1コマンド打つだけで、各プロジェクトの叩き台が
出勤前に揃っている状態をつくるための作業リポジトリです。

```
/night <今日のメモ>   → 寝る前3分。inbox に保存＋明朝への申し送りを作成
/morning              → 起床直後。曜日を判定して叩き台を生成し push まで完了
/review <コメント>     → 出勤後30秒。採用/差し戻しを記録し、型の改善材料にする
```

運用手順は **[docs/setup.md](docs/setup.md)** を参照。
前提・制約は `CLAUDE.md`（Claude が毎回自動で読みます）。

| ディレクトリ | 役割 |
|---|---|
| `prompts/` | 曜日別の実行プロンプト（①役割〜⑥確認ポイントの型） |
| `areas/` | 長期的に効く前提知識（事業所プロフィール、スカウトのルール等） |
| `inbox/` | 入力。日付ごとのメモ置き場 |
| `outputs/` | 出力。生成された叩き台 |
| `docs/` | 運用マニュアルと差し戻しログ |
