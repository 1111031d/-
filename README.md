# あいのわ訪問看護ステーション 経営OS

**夜に3分メモを書くと、朝起きたときに仕事の下書きができている** ——そのための置き場です。

覚える合図は3つだけ：

| 打つもの | いつ | 何が起きるか |
|---|---|---|
| `/night 今日あったこと` | 寝る前3分 | メモを保存し、実名を仮名に置き換え、翌朝の材料にまとめる |
| `/morning` | 起きた直後 | 曜日を見て、その日の仕事の下書きを作る |
| `/review 直したいこと` | 出勤後30秒 | 直しを反映し、理由を記録（土曜に自動で型が改善される） |

**まず読むもの → [docs/setup.md](docs/setup.md)（IT用語なしの使い方マニュアル）**

| フォルダ | 何が入っているか |
|---|---|
| `inbox` | あなたが入れる夜のメモ |
| `outputs` | 朝できあがる下書き |
| `prompts` | 曜日ごとのClaudeへの指示書 |
| `areas` | 事業所の基本情報など、変わらない前提 |
| `CLAUDE.md` | Claudeが毎回自動で読む共通ルール |
